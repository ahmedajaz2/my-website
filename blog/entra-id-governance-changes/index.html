🛡️ What's New in Entra ID Governance

🗓️ Published: October 2026 | ✍️ Author: Ajaz Ahmed

Identity governance in Entra ID has moved fast since summer. Between June and October, Microsoft shipped a stack of governance changes — some long-awaited, some quietly enforcing. Here is the rundown that matters if you run identity for a living, and what I would do about each one.

👤 User-Centric Access Reviews Finally Answer "Who Has What?"

Access reviews have always been resource-centric: pick an app or a group, then review who has access to it. User-centric access reviews (now generally available) flip the lens: pick a user and see everything they can touch across the environment in one unified view. For joiner-mover-leaver hygiene and audit season, this is the view reviewers actually wanted. Microsoft is also previewing reviews for disconnected applications, so even apps not integrated with Entra ID can be pulled into the review cycle.

Take: run your next quarterly review user-centric for privileged users first. You will find the stale access that the resource views kept missing.

🏢 Tenant Governance: One Pane for All Your Tenants

Generally available since August, Tenant Governance lets administrators manage tenants at scale through a single interface instead of hopping across portals. The real win is visibility into shadow tenants — the ones spun up outside IT that quietly become your biggest blind spot.

Take: if your organization grew by acquisition, or has developers spinning up tenants on their own, start here before your next audit does it for you.

🔄 Lifecycle Workflows Grew Up

Three upgrades worth knowing. You can now clone existing workflows, which open directly in the review-and-create page for tweaking — no more rebuilding from scratch. Agent identity sponsor tasks are in preview, extending lifecycle workflows to AI agent identities. And delegated workflow management plus expanded attribute triggers round out the set.

Take: if you hand-built joiner-mover-leaver workflows, clone and tweak instead of rebuilding. And start asking who sponsors your agents — that question is coming to your next access review.

🎟️ Entitlement Management Finally Handles External Users Properly

Since June, admins can directly assign external users who are not in the directory to an access package using just their email. They get invited in as guests and are governed from day one — no more "invite first, govern later" gap. You can also now revoke previously approved access package assignments from My Access.

Take: if you run partner or vendor access, rebuild those flows around direct assignment. The onboarding experience gets simpler and the audit trail gets cleaner.

🔒 Microsoft Closed the Hard-Match Takeover Vector

This one is pure defense, enforced in two steps. Since June 1, Entra Connect and Cloud Sync can no longer hard-match an incoming Active Directory user onto a cloud user that holds Entra roles — closing a path where manipulating AD attributes could take over a privileged cloud identity. Since July 1, Entra blocks modifying the on-premises object identifier after it has been mapped, so a synced user cannot be re-mapped to a different on-premises identity. Audit logging was enhanced to capture these events, and a Graph API now exists for controlled recovery when you legitimately need to remap.

Take: check your sync audit logs for blocked attempts. A block firing is a signal that someone — or something — tried something interesting.

💳 The Guest Billing Meter Is Now Enforced — Don't Get Caught Out

Enforcement of the Entra ID Governance guest billing meter is now in effect for Entitlement Management and Lifecycle Workflows, with Access Reviews enforcement landing later. Without a linked Azure subscription activating the governance-for-guests add-on, new guest-scoped governance configurations get restricted and guest governance actions can fail.

Take: this is the classic "it worked in dev" trap. Link the subscription now, before your next guest access package silently fails in production.

🤖 Governance Is Coming for Your AI Agents

The agent registry (public preview, part of Entra Agent ID) is a centralized metadata store of every deployed agent across Microsoft and non-Microsoft ecosystems — built for discovery, governance, and secure collaboration at scale. Combined with agent sponsor tasks in Lifecycle Workflows, Microsoft is clearly building the identity governance plane for non-human identities.

Take: if your organization is deploying Copilot Studio or Dataverse agents, the identity model you pick now is the one you will be audited on later. Treat agents like identities from day one.

📡 Also on the Radar

  • 🔑 Passkeys went default September 1: users on SMS or voice MFA get passkeys auto-enabled with a registration nudge. Microsoft retires its own SMS/voice delivery on February 1, 2027 — find your SMS-only users now.
  • 🔐 SSPR now demands registered methods: since September 7, self-service password reset only accepts explicitly registered authentication methods. Unregistered contact-attribute fallbacks are gone.
  • 🧱 Stricter sign-in CSP from mid-October: Entra ID sign-in pages will only run scripts from trusted Microsoft CDN domains. Kill any browser extensions or tools injecting scripts into login pages before enforcement bites.

💬 Closing Thoughts

One theme across all of it: governance is moving from "review what exists" to "govern everything — tenants, guests, and agents — from one place." The capabilities are here. The gap is operational: reviews nobody reads, workflows nobody clones, guest configs nobody licenses. Pick the two that hurt most and ship them before year-end.

  • ✅ Run one user-centric access review for your privileged users and see what the resource views missed.
  • ✅ Inventory your tenants with Tenant Governance — adopt or kill the shadow ones.
  • ✅ Link the Azure subscription for guest governance billing before something fails silently.
  • ✅ Clone, don't rebuild, your joiner-mover-leaver workflows — and add agent sponsor tasks where agents exist.
  • ✅ Audit sync logs for hard-match blocks; a firing block is worth investigating.
